Сервис представляет собой подписку на вебхуки гитхаб репозиториев

Взаимодействие происходит с помощью тг бота, вот его команды:
- /start
- /sub/{link}
- /unsub/{id}
- /list


Внутренняя логика построена на патерне "наблюдатель", пользователь скидывает вебхук с гитхаба в бот, бот подписывается на данный веб хуй и ожидает ивент коммита (изолированные потоки), при появлении ивента создается запрос в rabbitMQ об уведомлении и формируется тело ответа, после чего рассылается всем подписанным на ивент пользователям
