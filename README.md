# Сервис работы с вебхуками гитхаб репозиториев

## Взаимодействие происходит с помощью тг бота, его команды:
- /start            # начать чат
- /sub/{link}       # подписаться на вебхук
- /unsub/{id}       # отписаться
- /list             # список подписок


Внутренняя логика построена на патерне "наблюдатель", пользователь отправляет вебхук с гитхаба в тг бота, клиент подписывается на данный веб хук и ожидает ивент коммита (изолированные потоки), при появлении ивента создается запрос в rabbitMQ об уведомлении и формируется тело ответа, после чего рассылается всем подписанным на ивент пользователям 

## Пайплайн работы
 1. Пользователь регистрируется
 2. Пользователь добавляет источник событий
 3. Пользователь подписывается на источник
 4. В источнике происходит событие
 5. Система получает событие
 6. Система определяет, кому оно нужно
 7. Система доставляет уведомление
